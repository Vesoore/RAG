# Rag
Веб приложение на streamlit, реализующая rag подход, позволяющее получать ответы от llm по загруженному пользователем документу.

<img width="715" alt="screen" src="https://github.com/Vesoore/RAG/assets/74493192/be213e8a-f3fb-4aa9-a1d3-ae205624c81e">

# Использование
Для начала работы следует клонировать репозиторий и установить зависимости
```
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
 ```
Можно запускать, предварительно получив api ключи для yandexgpt или gigachat
